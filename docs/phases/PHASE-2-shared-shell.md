# Phase 2: Shared Shell

## Objective
Create a consistent site shell across all main pages without flattening the scrapbook personality.

## Scope
- Header behavior
- Navigation links
- Footer consistency
- Shared responsive rules
- Low-risk shared cleanup
- Shared CSS token layer
- Shayann site branding

## Target Files
- `site/assets/styles.css`
- `site/index.html`
- `site/sketches.html`
- `site/treasures.html`

## Planned Tasks
1. Create a clean site directory for implementation.
2. Build shared CSS tokens and layout primitives from the design blueprint.
3. Build header, navigation, and footer with real page links.
4. Apply Shayann branding across the new shell.
5. Seed each main page with phase-safe section structure.

## Success Criteria
- All main pages link to each other.
- Header and footer feel related across pages.
- No broad visual regression.
- Blueprints remain untouched as references.

- `site/sketches.html` created as the sketches page with shared shell.

- Primary navigation now links all three implemented pages.
